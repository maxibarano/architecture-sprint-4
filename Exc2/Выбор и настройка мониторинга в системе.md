## Мотивация.  
Заказы - это то на чем компания зарабатывает деньги,
поэтому необходимо мониторить состояния заказов для
выяснения причин их задержек.
Задержки заказов - потеря репутации на рынке, потеря репутации на рынке деградация числа новых клиентов и потеря текущих, что ведёт к потенциальному разорению и закрытию компании.
Также, мониторинг позволит собирать и визуализировать бизнес метрики для получения быстрой обратной связи о бизнесе, для более осознанного принятия решений, которые опираются на статистические данные. 

## Выбор подхода к мониторингу.  
Для api буду использовать "4 золотых сигнала"
Для хранилищ и брокера "RED"

## План действий.
1. Развернуть Sentry
2. Развернуть Clickhouse для сбора логов
3. Развернуть Grafana для визуализации метрик и
просмотра логов.
4. Развернуть и настроить Prometheus
5. Подключить в приложения клиенты для отправки ошибок
в Sentry
6. Определить метрики и предоставить их для Prometheus
7. Развернуть side-car агенты рядом с приложениями
для сбора логов и отправки их в хранилище.
8. Создать необходимые дашборды в Grafana
9. Настроить алертинг для критичного функционала
